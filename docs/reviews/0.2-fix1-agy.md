## Focus Area Verification

1. **L1 — `wrapBetweenItems` (`TextRules.kt`, `StatusScreen.kt`, `SourcesScreen.kt`, `TextRulesTest.kt`):**
   - [TextRules.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/common/TextRules.kt#L18-L23) splits on `" · "`, replaces internal spaces within each item with `\u00A0` (no-break space, Unicode line-break class `GL`), and rejoins items with `" ·\u00A0"`.
   - The only ordinary breakable space (`U+0020`) in the resulting string sits immediately before each `"·"`. Under UAX #14, a line can never break before or after `\u00A0`, so `"·"` is glued to the start of the following item and can never be stranded at the end of a line, nor can an item like `"Skipped\u00A01"` or `"skips\u00A01\u00A0word"` break mid-item.
   - Single-item strings without `" · "` (such as `"Events: All"` or `""`) return early unchanged (`if (items.size < 2) return text`).
   - `wrapBetweenItems` is only applied to two controlled summary strings ([StatusScreen.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/status/StatusScreen.kt#L412) and [SourcesScreen.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/sources/SourcesScreen.kt#L234)) containing localized count labels and integers (never user-entered names or search terms), so it cannot create unbreakable long user strings or RTL/BiDi issues.

2. **L2 — `LabelSwatch` outline colour (`FilterEditorScreen.kt`):**
   - [FilterEditorScreen.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/sources/FilterEditorScreen.kt#L201) switches the 1 dp circular border from `MaterialTheme.colorScheme.outlineVariant` (a low-contrast divider token that blends into dark card surfaces next to `#212121` "Midnight black") to `MaterialTheme.colorScheme.outline`.
   - In Material 3, `outline` is the high-contrast component border token in both dark and light themes, keeping dark swatches visible on dark surfaces and light swatches visible on light surfaces.

3. **L3 — 32 dp height for `FilterLine` on `SourcesScreen` (`SourcesScreen.kt`):**
   - [SourcesScreen.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/sources/SourcesScreen.kt#L219-L231) changes `FilterLine` from `heightIn(min = 48.dp)` + `Alignment.CenterVertically` to `heightIn(min = 32.dp)` + `padding(start = 36.dp, bottom = 8.dp)` + `Alignment.Top`, and [SourcesScreen.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/sources/SourcesScreen.kt#L264-L268) removes the 4 dp bottom padding on `SourceCheckRow` when `option.canFilter` is true.
   - **Assessment (32 dp vs. 48 dp):** **32 dp is the right trade-off here.** With 48 dp and vertical centering, ~14 dp of empty space sat above and below the single-line `bodyMedium` text, visually detaching `"Events: …"` from the calendar title above it (finding L3). With 32 dp and `Alignment.Top`, the text sits directly beneath the calendar name like a subtitle while still providing a full-card-width × 32 dp touch target down to the row divider.

4. **L4 — Lowercase relative time inside parentheses (`Format.kt`, `TextRules.kt`, `TextRulesTest.kt`):**
   - [Format.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/common/Format.kt#L28-L33) and [TextRules.kt](app/src/main/kotlin/de/tergelius/ttsync/ui/common/TextRules.kt#L30-L31) lowercase the first character via `relative.replaceFirstChar { it.lowercase(locale) }` when `abs(nowMillis - millis) < DateUtils.WEEK_IN_MILLIS`.
   - `formatRelative` is used exclusively inside `R.string.time_with_relative` (`"%1$s (%2$s)"` on `StatusScreen`).
   - In German, `"Vor 1 Minute"` becomes `"vor 1 Minute"` (with `"Minute"` keeping its capital noun initial) and `"In 40 Minuten"` becomes `"in 40 Minuten"`.
   - In English, `"5 minutes ago"` is unchanged (starts with a digit) and `"In 40 minutes"` becomes `"in 40 minutes"`, which reads more naturally inside parentheses (`"12 Nov, 14:43 (in 40 minutes)"`).
   - At `>= WEEK_IN_MILLIS`, where `DateUtils.getRelativeTimeSpanString` switches to an absolute date (e.g. `"Nov 5, 2026"` / `"5. Nov. 2026"`), `isRelative` is `false` and the capital letter is preserved.

5. **L5 — `generateLocaleConfig` and `resources.properties` (`app/build.gradle.kts`, `app/src/main/res/resources.properties`):**
   - Enabling `generateLocaleConfig = true` in [app/build.gradle.kts](app/build.gradle.kts#L86-L90) together with `unqualifiedResLocale=en` in [resources.properties](app/src/main/res/resources.properties#L1-L2) causes AGP to generate `_generated_res_locale_config.xml` with `en` (default) and `de`, wiring it into the merged manifest so Android 13+ lists the app under **Settings → App languages**.
